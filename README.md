# accenture-ai-studio-fall2025
AI Studio project with Accenture focused on trust &amp; safety in content moderation. Using NLP and deep learning to classify real vs. fake news, detect misleading content, and assign credibility scores to articles.

## 📂 Dataset
This project uses two datasets:  
- `true.csv` → news articles from reliable sources  
- `fake.csv` → fabricated or misleading news articles  

Both files are stored in the `/data` folder for convenience.
